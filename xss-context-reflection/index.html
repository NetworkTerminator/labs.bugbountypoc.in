✅ Working Payload:

<img src=x onerror=alert(1)>

📖 Deep Explanation:

  • The application reflects the name parameter directly into the page without sanitization.
  • In this lab, reflection happens via JavaScript in the browser (since it’s static hosting).
  • In real-world apps (PHP/Node/Python), the reflection happens in the raw server response.
  • <script> may not always work depending on where your input is injected.
  • But injecting an element like <img> with an onerror event triggers JavaScript successfully.
  • Lesson: Always check the context where your input lands in the HTML. The payload depends on that context.
