✅ Working Payload:

<img src=x onerror=alert(1)>

📖 Deep Explanation:

  • The application reflects the name parameter into the page using innerHTML without sanitization.
  • Direct <script> injection fails because it’s embedded inside surrounding text (Hello ...!).
  • Instead, we inject a new HTML element (<img>) with a broken source.
  • The browser tries to load the image, fails, and triggers the onerror event → executing our JavaScript (alert(1)).
  • Lesson: If <script> doesn’t execute, try alternate payloads like event handlers, attributes, or other elements based on the injection context.
