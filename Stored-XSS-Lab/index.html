✅ Working Payload:

<img src=x onerror=alert(1)>

📖 Deep Explanation:

  • The common payload <script>alert(1)</script> often fails because applications may filter <script> tags or break the JavaScript context.
  • In this lab, the comment input is stored and then reflected inside the HTML body without proper sanitization, creating a Stored XSS scenario.
  • By using <img src=x onerror=alert(1)>, we exploit an HTML element's event handler. The src is intentionally broken (x) so that the onerror JavaScript executes when the image fails to load.
  • This approach works because it bypasses script filtering and directly injects JavaScript into the event context.
  • When testing XSS, first identify the context where your input is reflected (HTML body, attribute, or JS context). Then choose a payload that fits the context and triggers execution. Here, HTML context is broken by using an <img> tag with an event.
  • Thus, <img src=x onerror=alert(1)> reliably triggers the alert, teaching the concept of context-based XSS payloads.
