Challenge

Click the button to reflect the name parameter from the URL into the page. Try to trigger an alert(1) pop-up.

💡 Hint Try injecting a <script> tag like: 
?name=<script>alert(1)</script>
📝 Show Answer & Explanation

✅ Working Payload:

<script>alert(1)</script>

📖 Deep Explanation:

  • The app uses innerHTML to insert user input directly into the DOM:
    • document.getElementById('output').innerHTML = `<p>Hello ${name}!</p>`;
  • When your input is <script>alert(1)</script>, the browser executes it as JavaScript.
  • This is called a DOM-based XSS vulnerability because the dangerous reflection happens entirely on the client-side JavaScript, without involving the server.
  • Fix: never use innerHTML with untrusted input. Use textContent or safe templating instead.
