Challenge

👉 Add ?name=yourinput to the URL, then click Show Name to reflect it on the page. Try to trigger an alert(1) pop-up.

💡 Hint Try injecting a payload that breaks out of the <p> tag, for example: 
?name=</p><img src=x onerror=alert(1)>
or 
?name=</p><script>alert(1)</script>
📝 Show Answer & Explanation

✅ Working Payload:

</p><img src=x onerror=alert(1)>

📖 Deep Explanation:

  • The app uses innerHTML to insert user input directly into the DOM.
  • Because the input is wrapped in a <p> tag, you need to break out of it: </p><img src=x onerror=alert(1)>.
  • This is a DOM-based XSS vulnerability because reflection happens entirely in client-side JavaScript.
  • Fix: never use innerHTML with untrusted input. Use textContent or safe templating.
