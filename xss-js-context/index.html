Challenge

Enter your name below. Your input will be placed inside a JavaScript string. Try to trigger an alert(1) pop-up.

💡 Hint Try breaking out of the string with something like ');alert(1);//
📝 Show Answer & Explanation

✅ Working Payload:

');alert(1);//

📖 Deep Explanation:

  • The lab places your input inside a JavaScript string context like: 
    console.log('Simulated execution with: USER_INPUT');
  • The payload ');alert(1);// works by:
    • ' closes the string.
    • ; ends the current statement.
    • alert(1); executes your injected JavaScript.
    • // comments out the rest to avoid syntax errors.
  • This demonstrates how XSS works inside a JavaScript context, where you must escape the string safely to inject code.
