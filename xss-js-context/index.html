Challenge

Your input will be placed directly into a JavaScript string. Try to break out of the string and execute JavaScript.

💡 Hint: Try breaking out of the string and injecting code.
📝 Show Answer & Explanation

✅ Working Payload:

");alert(1);//

📖 Explanation:

  • The input is reflected inside a JavaScript string, for example:
    var msg = "Hello USER_INPUT";
  • By using ");, we close the string and terminate the statement.
  • We then inject alert(1); as new code.
  • The // at the end comments out the remaining JavaScript to avoid syntax errors.
  • This results in execution of alert(1).
