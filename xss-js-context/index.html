📝 Show Answer & Explanation

✅ Working payload (example):

');alert(1);//

📖 Why it works:

  • The page takes the `name` parameter from the URL and is injected directly into a JavaScript context inside a script block (no sanitization).
  • If the `name` contains `');alert(1);//` it closes the string, injects `alert(1)`, then comments out the rest — causing immediate execution.
  • If this payload still doesn't run, it may be due to a browser CSP or caching — see troubleshooting steps below.
