💬 XSS Lab - Attribute Context

Challenge

Enter your name below. The value will be reflected inside an HTML attribute. Try to trigger an alert(1) pop-up!

💡 Hint Try breaking out of the value="..." attribute by using a quote (") and injecting a new event handler.
📝 Show Answer & Explanation

✅ Working Payload:

" onfocus=alert(1) autofocus="

📖 Deep Explanation:

  • The input is reflected inside an HTML attribute: value="...user input...".
  • Normal text like John is harmless: value="John".
  • Our payload starts with " → closes the value attribute.
  • Then we add onfocus=alert(1) → new event handler.
  • autofocus makes the input automatically focused on page load, so onfocus executes instantly.
  • The final = keeps the markup valid and prevents errors.
  • Lesson: In Attribute Context, breaking out of quotes allows you to inject new attributes that trigger JavaScript.
