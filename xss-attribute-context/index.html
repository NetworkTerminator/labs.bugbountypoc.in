Challenge

Enter your name below. It will be reflected inside an HTML attribute. Try to trigger an alert(1) pop-up by breaking out of the attribute!

Reflected Output:
💡 Hint Think about how to break out of the value="..." attribute and inject a new one with JavaScript.
📝 Show Answer & Explanation

✅ Working Payload:

" autofocus onfocus=alert(1)

📖 Deep Explanation:

  • The input is reflected inside an HTML attribute: value="...user input...".
  • If you enter just John, it becomes value="John" → safe.
  • By entering " autofocus onfocus=alert(1), we close the value attribute with " and inject two new attributes.
  • autofocus ensures the field is focused when the page loads.
  • onfocus=alert(1) runs immediately when the page focuses the field, triggering the popup without user interaction.
  • Lesson: In attribute context, escaping quotes lets you inject new attributes that execute JavaScript.
