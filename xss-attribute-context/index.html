Challenge

Enter your name below. Your input will be placed inside an HTML attribute. Try to trigger an alert(1) pop-up.

💡 Hint Try breaking out of the attribute with a quote and using an event handler like " autofocus onfocus=alert(1) x="
📝 Show Answer & Explanation

✅ Working Payload:

" autofocus onfocus=alert(1) x="

📖 Deep Explanation:

  • This lab puts your input inside an HTML attribute, for example: 
    <div style="color: USER_INPUT">This text has your color!</div>
  • The payload " autofocus onfocus=alert(1) x=" works by:
    • " closes the current attribute value.
    • autofocus forces the element to be focused automatically.
    • onfocus=alert(1) runs JavaScript when the element gains focus.
    • x=" is just filler to keep the HTML valid.
  • When the page loads, the input auto-focuses and triggers alert(1).
  • This demonstrates how XSS works in an attribute context, where escaping quotes and injecting event handlers is key.
