✅ Working Payload:

" onmouseover="alert(1)

📖 Deep Explanation:

  • The input is reflected inside an HTML attribute: style="color: ...".
  • A normal string like red just changes the text color.
  • By injecting " onmouseover="alert(1), we break out of the style attribute and start a new one (onmouseover).
  • Now, hovering over the text will execute alert(1).
  • Lesson: In attribute context, think about how to escape quotes and inject new attributes.
